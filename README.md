Documentation complète et officielle de **FluentCRM** - La solution ultime d'automatisation marketing pour WordPress.

## 📖 À propos

Ce dépôt contient la documentation complète de FluentCRM, extraite directement du site officiel [fluentcrm.com/docs](https://fluentcrm.com/docs). La documentation est disponible au format Markdown pour une consultation facile et hors ligne.

Cette documentation couvre tous les aspects de FluentCRM :

### 🚀 **Premiers pas**
- Installation et activation
- Configuration initiale
- Interface d'administration

### 👥 **Gestion des contacts**
- Import/export de contacts
- Gestion des listes et tags
- Champs personnalisés
- Segmentation avancée

### 📧 **Emails et campagnes**
- Éditeur d'emails drag & drop
- Templates d'emails

- Tests A/B

### ⚙️ **Automatisations**

- Triggers WooCommerce, LMS, Membership
- Actions conditionnelles
- Labels et organisation

### 📊 **Rapports et analyses**
- Tableaux de bord
- Statistiques de performance
- Suivi des événements
- Métriques détaillées

### 🔧 **Intégrations**
- WooCommerce

- MemberPress, Paid Membership Pro

## 🔍 Comment utiliser

### Consultation en ligne
1. Parcourez ce dépôt GitHub
2. Utilisez la recherche GitHub pour trouver des sujets spécifiques
3. Cliquez sur `FluentCRM_Documentation.md` pour voir la documentation complète

### Consultation locale
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/username/FluentCRM-Documentation.git
   ```
2. Ouvrez `FluentCRM_Documentation.md` dans votre éditeur Markdown préféré
3. Ou utilisez un viewer Markdown comme :
   - VS Code avec extension Markdown
   - Typora
   - Mark Text
